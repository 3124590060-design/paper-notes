A simple optical microscopy-based diatom classification approach for forensic drowning site inference: a pilot study

Ma, Chen, Yu, Chen, Ping Huang*, Zhang* · Int J Legal Med (2025) · 复旦大学 / 司法鉴定科学研究院
📌 一句话概括
用普通光镜+3个形态指标（对称性/轮廓/花纹）简化硅藻分类，以>90%准确率推断溺死地点——无需SEM和专家分类知识，适合资源有限实验室。
🗂️ 黄平课题组版图位置
主题#2：硅藻AI与溺死诊断（~12篇）
▸ 新维度：简化分类体系（此前工作侧重AI自动识别，本文侧重分类学简化）
▸ 与前作关系：DiatomNet v1.0的互补件——AI需要分类标准
🧬 研究范式
硅藻3指标分类 → 3D向量编码 → 丰度矩阵 → PCA降维 → 马氏距离 → 最小距离=推断溺死点
🎯 核心贡献（综述材料）
① 证明"简化分类"对溺死地点推断足够（不需物种级精度）
② 独有类型虽<5%但关键——稀有但忠实的信号
③ 大鼠模型验证体内vs体外一致性
④ 为AI提供低维标注标准(3D向量)

综述线索

A

法医硅藻学中的形态分类：从传统显微镜到AI驱动的简化体系

可行性 ★★★★★系统性强

逻辑链：传统分类（SEM+专家+1000×油镜）→ 本文简化分类（400×光镜+3指标）→ 分子方法（DNA barcode）→ AI自动化（DiatomNet）+ 简化分类的3D向量标注。这是硅藻分类方法的完整演进线。

维度评估
论文量黄平组~12篇(主题2) + 国际硅藻分类~10篇 + 分子方法~8篇 = ~30篇
竞争低。有硅藻检验综述，但"分类方法演进+AI融合"视角的几乎没有。
框架① 硅藻法医学基础 → ② 传统形态分类（SEM/油镜）→ ③ 分子分类（DNA barcode）→ ④ 简化形态+AI → ⑤ 多方法融合展望
B

溺死地点推断的方法学进展：从硅藻到多模态证据

可行性 ★★★★☆覆盖面广

逻辑链：溺死地点推断不只靠硅藻——还有水质化学分析、微生物组、同位素等。可以综述"各种方法在溺死地点推断中的比较"。本文是硅藻路线的最新代表。

维度评估
论文量硅藻~15篇 + 水质/微生物/同位素~12篇 = ~27篇
竞争中。有一些 drowning site inference 综述，但多模态比较的少。
框架① 法医学中溺死地点推断的重要性 → ② 硅藻法（形态/DNA/AI）→ ③ 水质标记法 → ④ 微生物组法 → ⑤ 多模态融合策略
C

低成本法医检验技术的开发与应用：资源有限环境下的策略

可行性 ★★★☆☆独特视角

逻辑链：本文核心卖点是"不需要SEM和专家"。在法医学中还有哪些"低成本替代方案"？可以围绕这个主题组织综述——本文和FTIR主题1的"光谱替代传统病理"异曲同工。
