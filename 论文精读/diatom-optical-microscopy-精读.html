📖 2.2 关键论证链

  • 为什么硅藻可以用来推断溺死地点？
  • 传统硅藻分类怎么做？为什么"难"？
  • 分子方法和AI方法有什么局限？
①

硅藻→溺死地点

溺死时硅藻被吸入肺泡→经毛细血管进入血液→栓塞至肝/肾/骨髓等器官。不同水域硅藻群落组成不同→比对器官和水样中的硅藻→推断溺死地点。

②

传统方法的痛点

需识别壳缝(raphe)、点纹(striae)、孔纹(areolae)等微细结构→需1000×油镜或SEM→需专家分类学知识→耗时、主观、贵。

③

替代方法的局限

分子方法(DNA barcode)：PCR非特异产物、成本高。AI方法：DiatomNet v1.0等已实现自动识别，但仍需大量标注数据。本文的简化分类方法可以赋能AI——用3D向量替代复杂标注。

🗂️ 3.1 方法分块

🔍 你的任务：方法分了几块？三类样本组分别是什么？

🧪 实验设计：三组样本

Group I（环境水样）：上海普陀区4个公园湖泊，每个5个采样点×1L水 → 硅藻基线数据
Group II（体外模型）：非溺死大鼠肺组织 + 各地点水样混合 → 体外验证
Group III（体内模型）：大鼠在各地点实际溺死 + 24h浸泡 → 肺组织硅藻分析 → 最接近真实场景
对照组：处死后浸水（非溺死）→ 肺内无硅藻 → 验证硅藻只能通过主动呼吸吸入

🔬 硅藻分类体系：3维向量编码

对称性(symmetry)：5类（辐射/双轴/反转/单轴/不对称）
轮廓(outline)：14类（圆/椭圆/纺锤/针/棒/弯/方/柳叶/舟/花生/糖果/水滴/双杠/飞镖）
花纹(pattern)：7类（空/锯齿/条纹/竖分/十字分/栅栏/同心圆）
→ 每种硅藻编码为(symmetry, outline, pattern)三维向量，如(2,4,1)

📊 统计分析

log转换+标准化 → PCA降维→取前3个主成分 → 3D散点图 → 计算马氏距离 → 最近水样中心=推断的溺死地点 → 混淆矩阵评估准确率

🧪 3.2 实验设计核心问答

  • 为什么用大鼠？用了多少只？
  • Control组证明了什么？
  • PCA+马氏距离的逻辑是什么？
✍️ 写完后揭晓答案
  • 动物：88只SD大鼠（280-300g）。Group II: 44只处死后取肺+水混合。Group III: 40只溺死+4只对照
  • 对照组的证明力：处死后浸水→肺内无硅藻 → 硅藻进入肺需要主动呼吸+循环，被动浸泡不够。这是硅藻检验法医学有效性的关键证据。
  • PCA+马氏距离：PCA降维可视化 → 水样聚类中心(centroid) → 未知样本到各中心马氏距离 → 距离最小=推断的溺死地点

📍 第五步：讨论精读

⏱ 15-20 分钟

💬 5.1 作者怎么解释？

  • 为什么要简化分类？（不只是省钱的问题）
  • 为什么传统精细分类对溺死地点推断"不必要"？
  • 作者设想如何与AI结合？
  • 简化≠粗糙：作者保留了14种轮廓（远超传统的"圆形/长形"二分法）+5种对称性（超越centric-pennate二分法），在简化和精度间找平衡
  • 为什么精细分类不必要：溺死地点推断需要的是地点特异性签名，不是物种级精确分类。就像你不需要知道每棵树的学名也能区分"热带雨林"和"针叶林"。
  • AI设想：简化分类→3D向量=天然适合AI训练。AI学对称性/轮廓/花纹→自动编码→建立动态更新的地区数据库→大规模溺死地点推断。

🧠 5.2 批判性思考

  • 这个方法的最大局限是什么？
  • 如果应用到实际案件，会遇到什么问题？
  • 和DiatomNet v1.0的关系是什么？
✍️ 写完后揭晓
  • 最大局限：① pilot study——仅4个独立湖泊，未验证连续水体（河流上下游硅藻群落可能渐变而非突变）；② 地区限定制——上海普陀区的数据库不能直接用于其他地区；③ 分类指标仍有主观性（尤其是花纹判断）。
  • 实际案件挑战：尸体在水中漂流→可能混入多段水体的硅藻；腐败气体+组织自溶→硅藻回收率下降。
  • 与DiatomNet v1.0：DiatomNet解决"自动化识别"，本文解决"简化分类体系"——互补关系。如果DiatomNet用本文的3D向量作为输出标签，可以极大降低标注复杂度。
  • 下一研究方向：① 连续水体验证（如黄浦江不同段）；② 3D向量+CNN自动分类；③ 多地区数据库建立和交叉验证。

📖 术语表

Diatom (硅藻)

单细胞光合藻类，有硅质细胞壁(frustule)。溺死时进入肺→血→器官。

Frustule

硅藻的硅质细胞壁，耐酸/耐腐败，是法医检验的核心对象。

SEM (扫描电镜)

可放大>10000×观察硅藻微细结构，传统分类依赖但设备昂贵。

Symmetry (对称性)

本文分5类：辐射/双轴/反转/单轴/不对称。

PCA (主成分分析)

降维方法：将高维硅藻丰度数据压缩到3个主成分，用于可视化和分类。

Mahalanobis Distance

马氏距离：考虑协方差的"加权欧氏距离"，比欧氏距离更适合分类。

Confusion Matrix

混淆矩阵：行=真实类别，列=预测类别。对角线上=分类正确。

DiatomNet v1.0

张吉课题组开发的深度学习硅藻自动识别软件（同课题组前期工作）。

Raphe/Striae/Areolae

硅藻壳缝/点纹/孔纹——传统分类需SEM观察的微细结构，本文方法不需要。

Pilot Study

初步验证研究——需更大范围验证才能推广。
